# 여러 글립 배치 보정 설계안

기본 구현 완료. 기존 `보정 범위`와 별도로 선택 글립 배치 패널을 사용한다. 되돌리기는 최근 배치 한 단계이며, 적용 후 해당 박스를 개별 수정했으면 덮어쓰지 않고 거부한다.

## 선택

- 상단 초중종 버튼: 화면에 나열할 글립을 필터링한다. 편집 대상 선택과 구분한다.
- 일반 클릭: 한 글립 선택. Shift 클릭: 현재 표시 순서 기준 연속 선택.
- Cmd(macOS)/Ctrl 클릭: 개별 글립 선택 추가 또는 해제.
- `표시 글립 전체 선택` 명령: 필터에 포함된 글립 전체를 편집 대상으로 선택한다.
- 필터를 바꾸면 편집 선택은 새 표시 범위와의 교집합만 유지한다. 숨은 글립에 보정하지 않는다.
- 확대와 패닝은 선택을 유지한다. 문자 재정렬 시 선택 글자 자체는 유지한다.
- 2350/2780 범위 배경은 옅은 바탕색, 편집 선택은 테두리로 표시해 둘을 혼동하지 않는다.

## 조정

- 사이드패널 상단에 선택 글립 수와 편집 역할(초성/중성/종성)을 표시한다.
- 여러 글립 선택 시 ΔX/ΔY/Δ너비/Δ높이는 0에서 시작하는 이번 작업의 추가 변화량이다.
- 각 글립의 현재 목표 박스(기존 수동 보정 포함)를 작업 시작 시 고정해 기준으로 쓴다.
- 각자 다른 박스에 같은 Δ를 더한다. 특정 글립의 절대 XYWH를 전부 복사하지 않는다.
- 여러 자소 종류도 선택할 수 있지만, 한 번의 작업에서는 같은 역할만 편집한다.
- 종성이 없는 글자, 목표 공간이 없는 글자 등은 생성하지 않고 제외 수와 이유를 표시한다.
- 여러 글립 선택 중에는 개별 박스 드래그를 배치 작업으로 해석하지 않는다.
  첫 구현은 사이드패널 Δ 입력으로 제한해 선택 동작과 변형 동작의 충돌을 피한다.

## 미리보기와 적용

- 입력 중에는 전체 선택 대상의 목표 박스만 임시 표시하고 Session/Font lib는 바꾸지 않는다.
- `선택 N자 보정 적용` / `취소`를 제공한다. 적용 한 번을 되돌리기 한 단위로 기록한다.
- 새 선택 또는 필터 변경 시 미적용 미리보기는 폐기하고 입력을 0으로 되돌린다.
- 적용 후 입력을 0으로 돌려 같은 변화량의 의도하지 않은 재적용을 방지한다.
- 기본 단위는 font unit. 비율 보정과 역할 간 자동 재배분은 별도 기능이며 여기서는 하지 않는다.
- 여기서 바뀌는 것은 목표 공간이다. FontLab 윤곽이나 SVC의 실제 갱신은 별도 적용 단계다.

## 검증 항목

- 서로 다른 초기 박스와 기존 보정값에 동일 Δ 적용, 선택 밖 글립 불변.
- 필터 변경 후 숨은 대상에 적용되지 않음, 범위 배경은 선택 여부에 영향 없음.
- 종성 없음/근거 부족 제외, 너비·높이 비정상 값 거부, 취소 시 데이터 불변.
- 미리보기 반복에 따른 누적 없음, 한 번의 되돌리기로 배치 전체 복구.
