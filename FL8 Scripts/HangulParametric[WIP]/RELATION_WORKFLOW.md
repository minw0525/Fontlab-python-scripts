# 관계 기반 파생의 제작 기준

## 기본 전제

현재 기준: 받친글자는 임의의 기준 글자 대신 ㅁ 조합 조건을 사용한다. 민글자(open)는 기존 독립 경로를 유지한다.
H/V/M과 open/closed는 관계 표본·소스·복사 윤곽 모두 분리한다. 다른 모임꼴이나 다른 받침 유무를 대체 근거로 사용하지 않는다.

초성·중성·종성은 서로 영향을 주는 조합 조건이다. SVC의 width/height 등 변형 축과 구분한다.
다른 자소에도 유사한 조건별 변화 경향이 나타날 수 있다는 가정을 출발점으로 사용한다.
기준 자소의 절대 크기를 대상 자소의 제작 목표로 복제하지 않는다.
구조적 차이는 조건별 보정 또는 별도 소스 연결로 처리한다.

## 데이터의 역할

1. 관계 표본: 조건별 변화, 극값 조건, 근거를 추정한다.
2. 대상 디자인: 실제 대상 자소의 윤곽과 치수를 제공한다.
3. 소스: 디자이너가 극값 조건에 맞춰 디자인한 변형 범위를 제공한다.
4. 보정: 관계 모델 위에 적용하는 조건별 차이다. 원본 표본을 수정하지 않는다.

같은 글립이 관계 표본과 대상 디자인에 모두 쓰일 수 있지만 용도는 구분한다.
현재 UI에서는 대상 디자인도 표본 분석 목록에 포함해야 읽힌다.
폰트의 미분석 글립을 자동 검색해 초중종을 판별하는 기능은 아직 없다.

## 예: ㅇ 표본에서 ㅁ 소스 만들기

- 악·안·암 등에서 너비와 높이의 변화 관계를 추정한다.
- 막·만·맘 등의 조건으로 바꾸어 극값 조건을 안내한다. ㅇ의 실제 W/H를 ㅁ 목표로 쓰지 않는다.
- 맘 실측만 있다면 맘의 ㅁ을 원래 크기로 복사하고 원점만 정규화한다.
- 복사한 네 윤곽이 같아도 오류가 아니다. 코너 디자인을 시작할 자료이며 아직 변형 소스가 완성된 것은 아니다.
- 맘 하나가 전체 ㅁ의 최소·최대 크기를 확정하지 않는다.
- 필요한 ㅁ 기준 실측이 없다면 근거 부족과 필요한 글자를 안내한다. 빈 소스 초안은 만들 수 있지만 location 적용은 보류한다.
- 너비 최소와 높이 최소 조건이 겹치지 않으면 합성 코너임을 안내한다.
- 변화가 관측되지 않은 축은 극값 조건이 미정이다. 같은 표본을 두 극값으로 확정하지 않는다.
- 같은 ㅁ/H/받친글자 소스의 안내는 막·맘 중 어느 것을 선택해 열어도 같다.
- 안내는 현재 표본을 사용한다. 기존 소스 윤곽과 생성 당시 note/Font lib 안내는 자동 갱신하지 않는다.

## 비례와 위치의 구분

두 조건 사이의 크기 변화율과 전체 범위에서의 정규화 비례는 다르다.
받친글자는 변화율로 목표 WH를 산출하고 실제 소스 응답으로 location을 역산한다.
기준 자소의 절대 WH를 그대로 사용하거나 정규화 비례를 곧바로 location에 넣지 않는다.
민글자는 기존 독립 경로를 유지한다.

받친글자의 위치는 고정된 대상 기준 조건에 관계 표본의 X/Y 변화량을 더한다.
예: 암(20,100), 악(25,120), 맘(40,300)이면 막은 (45,320)에 둔다.
초성: 막 = 맘의 초성 × (악의 초성 / 암의 초성). X/Y는 차이를 더한다.
종성: 각 = 막의 종성 × (감의 종성 / 맘의 종성).
중성: 각 = 맘의 중성 × (감의 중성 / 맘의 중성) × (막의 중성 / 맘의 중성).
마지막 식은 초성·종성의 중성에 대한 영향이 독립적으로 전이된다는 초기 가정이다. 실측으로 검토하고 조건별 보정해야 한다.
위 경로의 실측이 부족해도 중성·종성은 같은 모음의 실제 비교 쌍으로 전이할 수 있다.
예: 암·악·맘이 있으면 막의 중성/종성 = 악의 해당 자소 × (맘의 해당 자소 / 암의 해당 자소).
X/Y는 악에 맘−암 이동량을 더한다. 막을 추정하기 위해 막의 실측을 다시 요구하지 않는다.
해당 모음의 기준이 없으면 같은 모임꼴의 실제 비교 쌍으로 모음 간 전이를 허용한다.
예: 먹 초성 = 맘 초성 × (억 초성 / 암 초성). 먹 중성/종성 = 억의 해당 자소 × (맘의 해당 자소 / 암의 해당 자소). X/Y는 대응 차이를 더한다.
이때 멈을 실측한 것처럼 취급하지 않는다. `모음 간 전이`로 표시하며, 같은 모음의 기준 디자인이 생기면 우선한다. 여러 비교 쌍이 가능하면 같은 모음을 먼저, 나머지는 중성 유니코드 순으로 고정한다.
실제 출발 표본과 비교 쌍은 모두 필요하다. 맴만 있고 앰이 없다면 맘 대신 연결할 수 없다. H/V/M과 민글자/받친글자 사이에는 전이하지 않는다.
필요한 기준 조건이 없으면 정확한 필요 글자를 알리고 적용을 막는다. 예측값을 기준 표본으로 재학습하지 않는다.
직접 실측한 대상 글자는 실측값을 유지한다. 사용자 ΔXYWH는 한 번만 더한다.
소스 코너 제안은 계산 가능한 조건의 범위다. 미측정/근거 부족 조건이 있으면 전체 극값으로 확정하지 않는다.

## 구현 순서

- [x] 선택 글자의 실측/추정 상태와 무관하게 관계 프로필로 극값 조건 산출.
- [x] 대상 실측 디자인과 관계 조건을 분리하고 기준 자소 치수를 제작 목표에서 제거.
- [x] 대상 표본은 원래 크기로 복사, 없으면 빈 코너 생성. 기존 소스 보호.
- [x] 현재 표본의 안내와 생성 당시 note를 구분.
- [ ] 관계 기준의 명시적 선택/고정 UX. 자동 기준은 표본 수 변화에 따라 바뀔 수 있음.
- [x] 받친글자의 ㅁ 조건 기준 크기/위치 매핑을 한 경로로 통합. 임의 선택 UI 비활성화 및 이전 선택 무시.
- [x] reference 경로에 대상 배치 기준 + 상대 이동으로 X/Y 전이. 위치 기준과 근거 부족을 UI에 명시.
- [x] 평가 후 참고 박스는 점선, 실제 SVC 박스는 실선. 공간 · unit에 실제 SVC XYWH 표시.
- [x] 소스 연결 시 선택 범위의 같은 소스 조건을 일괄 평가하고 대상 유니코드 글립에 적용.
- [x] 기존 선택 자소를 마스크에 추가 백업하고 원래 요소 위치에 SVC 삽입. 나머지 역할과 기존 마스크는 보존. 실패 시 전경 복원 및 이번 백업 취소.
- [x] 같은 소스의 재적용은 기존 컴포넌트 location·transform만 수정. 최초 삽입·소스 변경에만 마스크 백업. 숫자/드래그/일괄 목표 조정 후 기존 SVC 자동 갱신, 실패 시 기존 값 복원. 과거 _hpResult 글립과 기존 마스크 백업은 변경하지 않음.
- [ ] 조건별 보정 및 형태 분기 UX 정리.

기존 inference.py의 일반 관계 예측은 저장 호환과 민글자용으로 남아 있다.
받친글자의 화면 박스/글줄 메트릭/소스 제안/평가/적용은 mieum_relations.py의 규칙을 사용한다.
표본 분석의 총 추론 수는 기존 엔진 수치일 수 있으므로 받친글자의 사용 가능 근거는 역할별 표시를 따른다.
