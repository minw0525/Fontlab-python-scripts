## 선택 사항: 중성별 기준 보정

optional_per_vowel.txt의 210자는 필수가 아니다. 다른 중성으로 전이했을 때 어색한 조건에만 사용한다.
예: 깜만으로 ㄲ H형을 연결할 수 있지만, ㅓ에서 ㄲ/ㅇ 비례가 다르면 껌을 추가해 해당 중성의 기준을 만든다.
